## 📌 Overview

This project was completed as part of my UI/UX Internship Program. The objective was to redesign a button set using Figma and leverage Variants to create reusable and interactive components.

## 🎯 Objective

Design and prototype a button system that demonstrates the effective use of Figma Variants for:

* Toggle Buttons
* Select Buttons

## 🛠️ Tools Used

* Figma

## ✨ Features

* Reusable button components
* Variants for different button states
* Consistent and scalable design system
* Interactive UI elements

## 🔄 Button Variants

### Toggle Buttons

* Default
* Active (On)
* Disabled

### Select Buttons

* Default
* Selected
* Disabled
